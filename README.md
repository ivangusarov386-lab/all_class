# Школьное расписание

Первый вариант приложения по расписанию школы: выбор параллели и одного из 70 классов, сегодняшний день по Москве, недельная лента, переключение дней стрелками и свайпом. Выбранный класс сохраняется в браузере. Дизайн следует приложению calendar: синий фон, крупный знак класса, светлое расписание.

## Разработка

Node.js 24, npm. В существующем checkout (создавать worktree не требуется):

```sh
npm ci --cache /tmp/school-npm-cache
npm run dev
```

Проверки: `npm test`, `npm run build`. Просмотр production-сборки: `npm run preview`.

## Публикация

В GitHub откройте Settings → Pages → Source → GitHub Actions. Workflow `.github/workflows/pages.yml` собирает и публикует сайт при push в main. После включения Pages при необходимости запустите Publish website вручную на вкладке Actions. Проект также можно опубликовать на любом статическом хостинге: build `npm run build`, каталог `dist`. Пути относительные, подходят для страницы репозитория.

## Данные

`public/data/schedule.json` — фактическое расписание из предоставленного `schedule_teachers_readable.xlsx`. 70 классов, 4 234 записи учителей/занятий, 6 дней, 10 возможных уроков. Повторные занятия разных учителей в один час сохранены вместе: назначение подгрупп в источнике отсутствует. Предметы взяты из заголовков разделов: объединённые русский/литература и история/обществознание не разделяются предположениями. В первых строках предмет не указан, это честно отмечено. Кабинеты — из строки учителя. Дата начала действия расписания в источнике отсутствует; приложение повторяет его еженедельно.

Обновить базовое расписание (нужен Python 3 и openpyxl):

```sh
python3 scripts/import_schedule.py /путь/к/расписанию.xlsx
```

## Замены и текущее ограничение

Источник: https://docs.google.com/spreadsheets/d/1vIOpBDYYJlVAnTNHKAvS8YBsIMK8wjV6HU3EACIqJSs/edit

Доступ к Google Таблице в среде разработки заблокирован сетевой политикой (403). **Её содержимое и фактическая структура пока не проверены.** Не добавлены выдуманные замены. Для завершения адаптера нужен экспорт этой таблицы XLSX.

Кнопка «Обновить замены» пытается загрузить XLSX напрямую из Google; это требует доступности экспорта без авторизации и разрешения CORS со стороны сервиса. Если загрузка не работает, используйте «Источники» → загрузить XLSX/CSV. Полностью статический сайт не может обойти закрытый доступ/CORS; для надёжной автоматической синхронизации после изучения структуры можно добавить серверный загрузчик или Apps Script.

Сейчас поддерживается явный табличный формат: `Дата`, `Класс`, `Урок`, `Предмет`, `Учитель`, `Кабинет`; дата ДД.ММ.ГГГГ или ГГГГ-ММ-ДД. Есть пустой CSV-шаблон. Загрузчик проверяет все листы: если хотя бы один лист не распознан или строка невалидна, весь импорт отклоняется с ошибкой, сохранённые данные остаются. Данные сохраняются только на устройстве пользователя. Новые замены красные, исходный урок зачёркнут. Для замены конкретной подгруппы используйте столбец `Кого заменяют` с точным ФИО исходного учителя; без него замена относится ко всем записям данного урока. Сохранённые данные не выдаются за успешно обновлённые при сетевой ошибке.

## Проверки

`npm test` проверяет импорт данных, разбор замен, отказ при ошибках и валидность дат. Production-сборка и браузерная проверка интерфейса должны выполняться перед публикацией. Настоящие замены остаются непроверенными до предоставления файла.
